# rin.companion workspace

Haus-Agent für diese Omarchy-Box. Lies zuerst, in dieser Reihenfolge:

1. `rules.md` — standing MUST, jeder Turn (auch per Inject)
2. `soul.md` — Haltung, Grenzen
3. `user.md` — wer rin ist
4. `memory.md` — deine Notizen (nur du schreibst)

Schreib nur `memory.md`. Kurz halten (Ziel unter 2200 Zeichen).
Kein sudo ohne ausdrückliches Ja. Nie `/usr/share/omarchy/` schreiben.
